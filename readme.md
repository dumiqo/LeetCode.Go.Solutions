## 3734 Lexicographically Smallest Palindromic Permutation Greater Than Target
**HARD**
Не справился за 1 час и применил решение из leetCode. Суть мыслей у меня была верная: у полиндроме может быть только одна буква встречающаяся нечетное количество раз, нужно составить только левую часть, а правую можно получить отзеркаливанием и применяются только lexicographically большие записи чем target. Я пытался просто собрать все возможные полиндромы и затем отсортировать их но можно было обойтись без полного перебора.

Преложенный вариант с leedCode находит нечетную букву и проверяет можно ли построить полиндром.
